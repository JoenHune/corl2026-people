本届研究与论文

Minimal-Intervention Target Retrieval in Cluttered Scenes with Grasp-Conditioned Dependency Graphs

Poster · 共同署名

摘要原文

Minimal-intervention target retrieval asks a robot to extract a target object from clutter while limiting non-target removals. The challenge is that a single scene may support multiple candidate grasps, and whether an object needs to be removed depends on the chosen grasp and the current execution stage, so scene-level clutter cues alone are insufficient. We address this with grasp-conditioned dependency graphs, where candidate grasps are action nodes and typed object-grasp edges represent approach- and lift-stage blockers. By tying blockers to concrete candidate grasps, the graph lets the planner distinguish objects that merely surround the target from those that are likely to block a particular grasp. To learn these dependencies, we run single-object intervention tests on 8,687 scene-target samples from 500 scenes, yielding 3,665,775 labeled edges, typed dependencies, and oracle minimal blocker sets. An action-centric edge-context model predicts object-grasp dependencies from observed scenes, and a short-prefix planner ranks blockers, selects a target grasp, and replans after each intervention. Stored-label planning provides a large-scale controlled test of the success-removal trade-off, closed-loop MuJoCo rollouts test the same policy under physical scene updates, and hardware trials validate the execution interface.
