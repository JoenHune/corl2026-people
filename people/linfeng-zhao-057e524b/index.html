本届研究与论文

MessyMem: Learning-from-Doing Memory for Mobile Manipulation

Poster · 共同署名

该篇个人署名单位：Stanford University

摘要原文

Mobile manipulators deployed at home across many rooms and many visits should improve with experience: after failing to open a locked cabinet, or finding an object in a drawer, the robot should use that knowledge to avoid repeated mistakes and complete future tasks more efficiently. However, today's robots often treat each task as new. Currently, compact scene representations omit interaction-derived knowledge, raw video buffers quickly grow to become inefficient and difficult to query, and VLM planners reason at inference time without persistently updating what the robot knows. Memory for mobile manipulation must be spatially grounded and queryable, updatable from interaction, and fine-grained enough to surface visual context that a text summary would lose. We present MessyMem, a memory system that enables mobile manipulators to learn from doing by building a compact 3D scene graph and associating it with learned interaction-derived properties and keyframes for visual detail. A task planner can use this memory to avoid repeated failures, reuse object locations, and recover visual context for long-horizon decisions. We evaluate MessyMem across multiple tasks in simulation and on a real mobile manipulator, showing that persistent interaction-grounded memory significantly improves long-horizon task success over representative baselines.
