本届研究与论文

Look Before You Move: Agent-Interface-Aligned Supervision for Open-World Mobile Manipulation

Poster · 共同署名

摘要原文

Open-world mobile manipulation (OWMM) requires a vision-language model (VLM) agent to do more than recognize a target: after visual contact, the robot must reacquire, approach, and stop at a pose from which pick or place can succeed. We argue that this failure is partly a supervision-interface mismatch. Synthetic teachers often succeed through privileged low-level execution traces that are later converted into VLM labels, while the deployed student must act from egocentric images, compact memory, and high-level skill calls. We introduce AIDA-OWMM, an agent-interface data alignment framework that collects active target-acquisition demonstrations directly in the deployed VLM agent interface and annotates them with object-centric spatial reasoning targets. On the OWMM benchmark, AIDA-OWMM raises full-task success from 7.65% for an exact OWMM-style legacy baseline to 71.76%, with the largest gains appearing after object retrieval, in pick readiness, object pickup, goal search, and final task completion. Cross-benchmark EmbodiedBench navigation results further suggest that the same supervision format transfers beyond the original mobile-manipulation benchmark. Code will be publicly released.
