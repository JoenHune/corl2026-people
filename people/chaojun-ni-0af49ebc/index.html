Native Memory Compression for Long-Horizon Robotic Manipulation

Poster · 共同署名

该篇个人署名单位：Peking University

摘要原文

How can pretrained Vision-Language-Action (VLA) models retain long-horizon visual histories with high-frequency updates without sacrificing efficiency? Existing approaches rely on external memory management, which restrains either the memory horizon or the reactiveness of pretrained policies. To this end, we present NativeMEM, a VLA policy that features long-term and real-time updated memory. At its core is an efficient memory encoding scheme, Native Memory Compression, which repurposes the VLA's own vision encoder to compress each historical frame from each camera view into a single token. Appended to the input sequence, these memory tokens enable the pretrained VLA to attend over long-term history with negligible latency overhead, requiring neither an external planner nor a freshly initialized memory module. To align the memory tokens with the pretrained policy, we first develop a generic memory tokenizer under the supervision of a frozen VLA on memory-demanding data, and then unfreeze the VLA for task-specific fine-tuning. NativeMEM consistently outperforms prior methods, boosting success rates from 32.4% to 84.0% in simulation and up to 98.7% on real robots, while maintaining low inference latency and GPU memory usage. Notably, NativeMEM exhibits high data efficiency by achieving competitive results with prior arts using only 20% of the training data.

WAM-STEP: Self-Improving World-Action Models Through Efficient Post-Training

Poster · 共同署名

摘要原文

World Action Models (WAMs) improve robot policies by predicting future visual consequences, but inference-time video prediction increases latency. Recent efficient WAMs avoid this cost by using the visual branch only during training and deploying an action-only policy. However, predicted futures remain an auxiliary loss and do not explicitly guide policy improvement. We propose WAM-STEP, an efficient post-training framework that turns the training-only visual branch of a WAM into an internal imagination module for self-improvement. WAM-STEP first calibrates the visual branch on mixed-quality policy rollouts to model policy-induced outcomes, using an action-conditioned preference loss to improve action-following future prediction. It then freezes the calibrated visual branch and optimizes the action branch using reward-scored imagined futures, with a policy-anchor baseline to stabilize group-relative updates. This enables efficient consequence-to-action feedback without introducing a separate world-model simulator or adding video generation at inference. On RoboCasa365, WAM-STEP improves the base policy from 20.7% to 24.0% average success. On two real-world tasks, WAM-STEP achieves 62.5% average success, outperforming the base policy by 20 points. These results show that training-time visual consequences can be internalized into stronger action-only robot policies.

Enhancing Robotic Control Robustness through Generative Visual Model

Poster · 共同署名

该篇个人署名单位：Peking University / GigaAI

摘要原文

The generalization of vision-language-action (VLA) models heavily relies on diverse training data. However, acquiring large-scale robot manipulation data across varied object appearances is costly and labor-intensive. To address this, we introduce Embodied Manipulation Media Adaptation (EMMA), a framework for augmenting VLA policies that combines a generative data engine with an effective training pipeline. We introduce DreamTransfer, a diffusion Transformer-based architecture for generating multi-view consistent and geometrically plausible embodied manipulation videos. It supports text-driven video editing on foreground, background and lighting while preserving 3D structure and geometric fidelity. We also utilize a hybrid training set of real and generated data and propose AdaMix to enhance the training process. AdaMix is a training strategy that adaptively weights samples according to policy performance to emphasize challenging samples. Evaluations show DreamTransfer outperforms previous video generation models in multi-view consistency, geometric fidelity, and text-conditioning precision. We conduct over 1800 trials across simulation and real robot platforms. In real-world robotic tasks with zero-shot visual settings, our framework achieves a relative performance increase of over 92% compared to training with real data alone, and improves by an additional 17% with AdaMix.
