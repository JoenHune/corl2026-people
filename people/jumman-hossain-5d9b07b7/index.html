本届研究与论文

CoGeL: Constraint-to-Geometry Learning from Demonstrations and Failures for Safe Long-Horizon Robot Navigation

Poster · 首位署名

摘要原文

Robots are often deployed in environments where safety must be learned from experience rather than specified in advance. Demonstrations, operator interventions, near misses, and failed rollouts can reveal which behaviors are risky, but they provide only local evidence. The key challenge is not only to identify risky behavior, but to make that knowledge shape the distance a robot uses for long-horizon planning. Existing goal-conditioned methods can compose short behaviors into longer plans, but they usually assume the safety-relevant cost is already known. We introduce CoGeL, a constraint-to-geometry learning method that learns a soft safety signal from robot data and incorporates it directly into the goal-reaching distance used for planning. This makes the learned distance safety-aware, instead of treating safety as a separate classifier, hard mask, or post-hoc filter. We show that errors in the learned safety signal lead to controlled changes in the navigation geometry, that approximate distance consistency supports long-horizon composition through waypoints, and that calibrated safety scores limit the expected number of true violations. Experiments across different navigation tasks show that CoGeL substantially reduces unsafe events while preserving strong long-horizon goal-reaching.
