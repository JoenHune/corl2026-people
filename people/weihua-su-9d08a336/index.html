本届研究与论文

WAM-STEP: Self-Improving World-Action Models Through Efficient Post-Training

Poster · 共同署名

摘要原文

World Action Models (WAMs) improve robot policies by predicting future visual consequences, but inference-time video prediction increases latency. Recent efficient WAMs avoid this cost by using the visual branch only during training and deploying an action-only policy. However, predicted futures remain an auxiliary loss and do not explicitly guide policy improvement. We propose WAM-STEP, an efficient post-training framework that turns the training-only visual branch of a WAM into an internal imagination module for self-improvement. WAM-STEP first calibrates the visual branch on mixed-quality policy rollouts to model policy-induced outcomes, using an action-conditioned preference loss to improve action-following future prediction. It then freezes the calibrated visual branch and optimizes the action branch using reward-scored imagined futures, with a policy-anchor baseline to stabilize group-relative updates. This enables efficient consequence-to-action feedback without introducing a separate world-model simulator or adding video generation at inference. On RoboCasa365, WAM-STEP improves the base policy from 20.7% to 24.0% average success. On two real-world tasks, WAM-STEP achieves 62.5% average success, outperforming the base policy by 20 points. These results show that training-time visual consequences can be internalized into stronger action-only robot policies.
