One-Step World Models for Multi-Modal Goal Navigation

Poster · 首位署名

摘要原文

World-model-based planning is a promising direction for robot navigation because it enables explicit prediction of future observations under candidate actions. However, existing navigation world models typically rely on multi-step diffusion and autoregressive frame generation, which substantially increases model-side latency and complicates closed-loop deployment. In this work, we present a lightweight one-step world model for navigation built on a 3D U-Net with efficient spatial-temporal attention. The model predicts all future frames non-autoregressively in a single pass, while pretraining and random trajectory sampling improve performance in limited-data settings. We integrate this world model into a unified planning framework that supports image-goal, language-goal, and point-goal navigation through modality-specific scoring functions and anchor-based trajectory initialization. Extensive closed-loop experiments in both simulation and real-world environments show that the proposed approach improves generation efficiency and achieves strong navigation performance against state-of-the-art baselines.
