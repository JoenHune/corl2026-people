本届研究与论文

DexHandover: Learning Bimanual Dexterous Handovers from Large-Scale Synthetic Data

Poster · 共同署名

摘要原文

Object handover between two dexterous hands is a fundamental yet underexplored skill for bimanual robots. Unlike single-hand grasping, dexterous handover requires anticipatory coordination: the giver must leave clearance for the receiver while both hands manage finger-level contacts and avoid interference. We address this challenge with DexHandover, a generative ``Shape-to-Motion'' framework that maps an object's geometry directly to a complete bimanual handover motion sequence. DexHandover combines: (i) an optimization-based pipeline for generating large-scale synthetic dataset of physically validated bimanual handover poses; (ii) a two-stage generative model that predicts handover poses conditioned on object geometry; and (iii) a reinforcement learning strategy that synthesizes physically plausible giver-to-receiver motion sequences anchored at the generated handover pose. We validate the pipeline in simulation and retarget the synthesized trajectories to robot hands, demonstrating reliable robot-to-robot dexterous handover from object geometry.
