本届研究与论文

CoReMatch: Recurrent Continuous Coordinate Refinement for Real-Time Robotic Feature Matching

Poster · 共同署名

摘要原文

Feature matching is a fundamental component of robotic perception systems, enabling visual localization, mapping, SLAM, and autonomous navigation. Existing semi-dense matching methods formulate correspondence estimation as discrete confidence prediction over feature grids, inherently producing grid-aligned correspondences that require increasingly high-resolution feature maps for accurate localization, resulting in substantial computational and memory overhead that limits real-time deployment on embedded robotic platforms. We propose CoReMatch, a recurrent coordinate refinement framework for efficient semi-dense feature matching. CoReMatch reformulates semi-dense matching as iterative coordinate-space optimization and progressively refines correspondences through recurrent hidden-state propagation. At the coarse level, a Deep Aggregated Transformer performs efficient global correspondence refinement through recurrent coordinate updates. At the fine level, a lightweight local refinement module predicts sub-pixel coordinate corrections within compact feature windows for accurate geometric refinement. Extensive experiments on indoor and outdoor benchmarks demonstrate that CoReMatch achieves superior accuracy--efficiency trade-offs compared with state-of-the-art semi-dense matchers. In particular, CoReMatch achieves higher accuracy on MegaDepth while delivering over 10x faster inference than Efficient LoFTR on embedded edge devices. These results suggest that recurrent coordinate refinement provides an efficient and scalable formulation for real-time robotic perception.
