SAGE-3D: Semantic-Aware 3D Representations for Generalizable Vision-Language-Action Models

Poster · 首位署名

摘要原文

Vision-Language-Action (VLA) models have shown strong potential for language-conditioned robotic manipulation, but their reliance on 2D visual backbones limits precise reasoning about depth, spatial relations, and contact-rich actions. We propose SAGE-3D, a semantic-aware 3D VLA framework that aligns geometric structure with task semantics for instruction-conditioned action prediction. Motivated by representation analysis, our key insight is that effective 3D VLA policies require both transferable geometric cues and instruction-relevant semantic grounding: geometry should not be injected as an isolated modality, but organized around objects, relations, and affordances relevant to the task. To realize this, SAGE-3D introduces a 3D Semantic-Aware Feature Generator (SAFG), which integrates RGB semantics, depth information, and task instructions to produce 3D Reasoning Tokens. These tokens are injected into the action head through a FiLM-based geometry-conditioned decoder, allowing semantic-aware spatial context to directly modulate action generation. Extensive experiments in simulation and real-world manipulation show that SAGE-3D improves overall benchmark performance and training efficiency, with the largest gains on spatially demanding tasks. Notably, SAGE-3D reaches 100% success on LIBERO-Spatial, establishing a new state-of-the-art result and, to our knowledge, the first result to saturate this benchmark. Anonymous code is available at https://anonymous.4open.science/status/SAGE3D.

WAM-STEP: Self-Improving World-Action Models Through Efficient Post-Training

Poster · 共同署名

摘要原文

World Action Models (WAMs) improve robot policies by predicting future visual consequences, but inference-time video prediction increases latency. Recent efficient WAMs avoid this cost by using the visual branch only during training and deploying an action-only policy. However, predicted futures remain an auxiliary loss and do not explicitly guide policy improvement. We propose WAM-STEP, an efficient post-training framework that turns the training-only visual branch of a WAM into an internal imagination module for self-improvement. WAM-STEP first calibrates the visual branch on mixed-quality policy rollouts to model policy-induced outcomes, using an action-conditioned preference loss to improve action-following future prediction. It then freezes the calibrated visual branch and optimizes the action branch using reward-scored imagined futures, with a policy-anchor baseline to stabilize group-relative updates. This enables efficient consequence-to-action feedback without introducing a separate world-model simulator or adding video generation at inference. On RoboCasa365, WAM-STEP improves the base policy from 20.7% to 24.0% average success. On two real-world tasks, WAM-STEP achieves 62.5% average success, outperforming the base policy by 20 points. These results show that training-time visual consequences can be internalized into stronger action-only robot policies.
