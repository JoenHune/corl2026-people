# CoRL 2026 公开发布包

仅发布本目录 `dist/corl-people/` 的内容；不要发布项目根目录、`papers/`、`data/raw/`、缓存或个人备份文件。

- `index.html` 是选人与分组工作台；`authors.html` 保留为固定别名和深链接入口。
- GitHub Pages 可将此目录内容作为站点产物发布。`.nojekyll` 保持原样。
- 链接和资源采用相对路径，同时支持站点根地址和 `https://<owner>.github.io/<repository>/` 项目子目录。
- 作者静态介绍位于 `people/`，无需执行脚本；`data/authors-index.json` 是助手数据入口。
- 所有论文、PDF 和研究来源均链接至公开 HTTPS 地址；本包不含本地论文 PDF。
- 必见、分组、个人备注和姓名分类修正保存在使用者浏览器中，不写入公共文件或服务器。
- 更换浏览器、设备或域名前，请在工作台导出完整个人备份，再在新入口恢复。
- 更新公共资料时替换发布产物即可；同一来源的个人浏览器工作区不会被更新覆盖。

本包已准备供发布，但生成 ZIP 不代表网站已经上线。
