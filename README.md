# CoRL 2026 People

[打开会场选人与分组工作台](https://JoenHune.github.io/corl2026-people/) · [助手资料](https://JoenHune.github.io/corl2026-people/assistant.html)

CoRL 2026 公开研究资料、作者介绍、必见名单与个人分组。支持检索 4,066 个作者标识与 687 篇录用论文，并提供无需执行 JavaScript 的作者资料和 AI 助手推荐导入格式。

## 使用

- 用搜索、研究方向、单位地区和拼音姓名筛选作者；展开介绍查看研究组合及原文依据。
- 标记必见，建立自己的组；同一作者可以加入多个组。
- 个人名单、分组、备注与姓名分类修正仅保存在使用者浏览器，不会上传到 GitHub 或网站服务器。换设备或域名前，请从工具菜单备份并恢复。
- 助手从 `assistant.html`、`llms.txt` 与 `data/authors-index.json` 开始读取资料；推荐按稳定作者 ID 导入。

## 资料与标识

论文、角色与单位信息保留来源和未知状态。姓名拼写分类不表示族裔身份，录用也不代表作者一定到场。

这是独立研究工具，并非 CoRL 官方网站。官方标志原图来自 [CoRL Organization Board 公告](https://www.linkedin.com/posts/corl-organization-board-499a28310_corl2026-robotlearning-robotics-activity-7431935361615859712-7djx)，标志权利归其权利人；完整出处见 `assets/corl2026-logo-source.json`。[会议官网](https://www.corl.org/)。

此仓库仅包含经过白名单构建的公开发布产物，不包含本地论文全文库、原始抓取、缓存或个人工作区。`.nojekyll` 保持原样，GitHub Pages 从 `main` 分支根目录发布。
